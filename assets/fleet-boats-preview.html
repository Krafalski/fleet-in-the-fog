Code to grey a boat out

.boat--locked { filter: grayscale(1); opacity: 0.3; }   /* not earned yet */
.boat--year2  { filter: invert(1) hue-rotate(180deg); } /* second time around */
.boat--year3  { filter: grayscale(1) contrast(1.15); }  /* third time around */
